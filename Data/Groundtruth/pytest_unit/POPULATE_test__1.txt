**Test Object**
`POPULATE.POPULATE` function

**Test Goal**
Verifies that under a uniform distribution, the output `x` is identical to the original vector, and the values ​​of `y` are all between 0 and 1.

**Test Activities**
1. Construct an integer vector `x` ranging from 0 to 98 with a step size of 2.
2. Call `POPULATE.POPULATE` with the parameters `distribution="uniform"`, `lower_bound=0`, and `upper_bound=1`.
3. Check that the output `res.x` is exactly the same as the input `x.v`.
4. Check that all values ​​of `res.y` are less than 1 and greater than 0.
