**Test Object**
A rich text editor within an iframe

**Test Goal**
Exercise iframe loading through the plugin, text entry, selection, and the bold button; the code does not inspect the final bold formatting.

**Test Activities**
1. Open the page containing the iframe.
2. Use `frameLoaded` to wait for the iframe to finish loading.
3. Use the `iframe` command to locate the editor and type "Hello" to select all.
4. Click the bold button.
